# 🦁 Zoo Health Monitoring System

## Project Description
An advanced real-time monitoring system designed to track and analyze the health conditions of zoo animals using computer vision and machine learning. The system processes images to detect potential health issues, maintains historical health data, and provides immediate alerts when anomalies are detected.

The application is built using Flask, a Python web framework, and features a PostgreSQL database for storing animal and image data. Additionally, the system sends alert notifications via email when significant changes are detected, ensuring that zookeepers can respond promptly to any potential health issues. 🐾

## Technologies Used
### Backend

Python 3.8+: Core programming language
Flask: Web framework for the REST API and server-side operations
OpenCV (cv2): Image processing and computer vision tasks
SQLite3: Database management for storing animal and health data
NumPy: Numerical computations and array operations
Threading: Asynchronous processing of alerts and notifications

### Frontend

HTML5/CSS3: Modern web interface
JavaScript (ES6+): Client-side functionality
Bootstrap 5.3: Responsive design framework
Chart.js: Real-time data visualization
WebSocket: Real-time updates and notifications
Grid.js: Dynamic data grid management

### Monitoring & Analytics

Prometheus: Metrics collection and monitoring
DataDog: Advanced system monitoring and analytics
Slack Integration: Real-time alerts and notifications

### Development Tools

Git: Version control
Visual Studio Code: Primary IDE
Docker: Containerization (optional)
pytest: Unit testing
Black: Code formatting
flake8: Code linting
